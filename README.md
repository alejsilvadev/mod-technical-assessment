# JSONPlaceholder Posts

A small Next.js app that lists posts from the [JSONPlaceholder](https://jsonplaceholder.typicode.com/) API and lets you open each one to read the full post. Built as a technical assessment.

## Features

- Homepage listing 10 post titles fetched from the API
- Post details page showing the title and body of a single post
- A simple counter tracking how many posts you've read during the current visit

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- React
- TypeScript
- Tailwind CSS

## Running locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

- `npm run dev` – start the local dev server
- `npm run build` – build for production
- `npm run start` – run the production build locally
- `npm run lint` – run ESLint
