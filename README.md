# MOD JSON Posts

A small Next.js app that lists posts from the [JSONPlaceholder](https://jsonplaceholder.typicode.com/) API. Click a post to read the full thing, and there's a counter that tracks how many you've read this visit.

Live demo: https://mod-technical-assessment.vercel.app/

## Running it locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

Other scripts:

- `npm run build` – production build
- `npm run start` – run the production build
- `npm run lint` – run ESLint
